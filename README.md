# StudyLife Capture

A Chrome extension (Manifest V3, TypeScript) for saving selected text or whole articles into
[StudyLife](https://github.com/lukislp/studylife) as notes. AI enrichment (course assignment via
embedding similarity, tags, optional summary) is handled by
[studylife-ai](https://github.com/lukislp/studylife-ai), which already runs the LLM, embeddings,
and Qdrant index StudyLife's chat/agent features use.

Status: early development, not yet functional.
